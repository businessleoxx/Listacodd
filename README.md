# Lista de Exercícios em PHP

Coleção de 12 scripts de console para praticar operações, cálculos e leitura de valores com PHP.

## Exercícios

| Arquivo | Conteúdo |
| --- | --- |
| ex1.php e ex10.php | Expressão aritmética e precedência de operadores |
| ex2.php | Média ponderada |
| ex3.php | Celsius para Fahrenheit |
| ex4.php | Cálculo de IMC |
| ex5.php | Perímetro de retângulo |
| ex6.php | Estimativa de dias a partir da idade em anos |
| ex7.php | Velocidade média |
| ex8.php | Cálculo de troco |
| ex9.php | Área de triângulo |
| ex11.php | Lucro de uma venda |
| ex12.php | Segundos em uma semana |

## Requisitos

- PHP com suporte à execução em linha de comando

## Como executar

Na pasta do projeto, execute o script desejado:

php ex1.php

Substitua ex1.php pelo exercício que deseja executar. Os scripts que solicitam valores recebem a entrada pelo terminal.
